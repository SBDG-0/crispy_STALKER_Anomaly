# Fatal Error + Milspec PDA MCM Text String Patch

**Version:** `1.0.0.0`

## Description

Fixes missing MCM text and improves wording for Fatal Error and Milspec PDA.

## Preview

<img src="https://github.com/user-attachments/assets/ff554476-65f3-45ba-854a-e754bc4f5ce2" alt="Corrected Fatal Error and Milspec PDA MCM text" width="900" />

## Requirements

- [Milspec PDA 1.18.1 - catspaw](https://www.moddb.com/mods/stalker-anomaly/addons/milspec-pda-for-anomaly-151-152-and-gamma)
- [Fatal Error 1.7.9.5 - ncenka](https://www.moddb.com/mods/stalker-anomaly/addons/fatal-error-by-ncenka)

## Installation

Install the ZIP from [releases](https://github.com/SBDG-0/crispy_stalker_anomaly/releases) as a separate mod in MO2.

Enable it after the required addons and let it win conflicts for `gamedata/configs/text/eng/st_fe_mcm.xml`. This is a complete replacement English string table; merge it manually with other changes to that file. This package does not include a Russian translation or any gameplay scripts.
