# Custom Loading Screen Background for Multiplayer

**Version:** `1.0.0`

## Description

Replaces the loading-screen background with artwork selected for multiplayer.

[Art by damianskii: hunter and prey](https://www.deviantart.com/damianskii/art/Hunter-and-prey-1373042071)

<img src="https://github.com/user-attachments/assets/86471905-0200-49c0-9369-188a5af9516c" alt="Custom loading-screen background" width="900" />

## Installation

Install the ZIP from [releases](https://github.com/SBDG-0/crispy_stalker_anomaly/releases) as a separate mod in MO2.

Enable it in Mod Organizer 2.
