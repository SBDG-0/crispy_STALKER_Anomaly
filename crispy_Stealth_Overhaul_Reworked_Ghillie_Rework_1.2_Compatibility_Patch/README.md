# Stealth Overhaul Reworked + Ghillie Rework Compatibility Patch

## Description

Lets you use Ghillie Rework 1.2 with Stealth Overhaul Reworked, keeping ghillie camouflage while moving and Reworked's other stealth features.

**Version:** `1.0.0.0`

## Features

- Ghillie camouflage works while standing, walking, or crouching on natural ground, including grass, dirt, and bushes.
- Crouching makes you harder to spot. Camouflage starts working at 10 metres.
- Firing an unsuppressed weapon briefly makes you easier to spot.
- Keeps your regular outfit's camouflage when the ghillie terrain bonus does not apply.

## Requirements

- S.T.A.L.K.E.R. Anomaly 1.5.3.
- [Stealth Overhaul Reworked](https://github.com/Alex-leon1594/Stealth_Overhaul_Reworked/blob/main/MODDB_DESCRIPTION.md).
- [Ghillie Rework 1.2 by jaggervorog](https://www.moddb.com/mods/stalker-anomaly/addons/ghillie-rework).
- Optional: Mod Configuration Menu (MCM) to adjust ghillie settings.

## Installation

1. Install both required mods in Mod Organizer 2.
2. Install this patch as a separate mod and enable it.
3. Place it below both mods in MO2's left pane so the patch wins any conflicts.
4. Disable Stealth 2.31 and the old Stealth 2.31 + Ghillie compatibility patch when using Reworked.

## Settings

In MCM, open **Ghillie Suit Config** to adjust camouflage and the effect of unsuppressed shots. Lower visibility values make you harder to spot. The patch also works without MCM.

If you used Ghillie Rework or the older patch before, review these settings after switching.

## Compatibility

This patch has not yet been tested extensively and is considered in beta phase. Multiplayer compatibility is unconfirmed. <br> Check for an updated patch before updating Stealth Overhaul Reworked.
